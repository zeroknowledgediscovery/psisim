What you are looking at

The state is not one answer per survey item, but a probability distribution over the possible answers of every modelled GSS item: Ψ = (p1, …, pd). It starts at the empty state Ψ0, the distributions implied by the trained model when no answers have been supplied. Each dot is one item.

Faint lines are the learned dependencies of the native LSM: item i is linked to item j when the tree that predicts j uses i.

What an answer does

Picking a topic i draws an answer σ ~ pi from its current distribution and clamps it. Wave 0 (the splash) propagates Δi = δσ − pi through the centred kernels Kj←i(·|s) = φj(x∅, Xi=s) to every dependent item. Each later wave (the ripples) propagates only the change it newly induced, Δj = pjafter − pjbefore, to the items that depend on j.

No answer ⇒ no motion: Ψ0 is exactly stationary. Everything that moves was moved by an answer.

How not to read it

  • Links are learned statistical dependencies between survey responses. They are not causal links.
  • This is a model of survey-response dependencies, not a picture of a brain.
  • Waves are undamped at response scale 1 and need not die out on their own; each answer's wave train is stopped after the configured number of waves and the remaining perturbation is reported.
  • Positions are a layout for readability. Screen distance and ripple timing do not represent physical propagation time — each wave is one discrete simulation snapshot.
