What Ψ is

Ψ = (p1, …, pd) holds one response distribution for every item of the selected survey's Large Science Model (LSM). Each small sparkline below is one pi: a histogram over that item's possible answers. Before any answer, Ψ = Ψ0, the distributions the trained model implies for an empty survey, and it does not move on its own.

What asking does

Asking item i draws an answer σ ~ pi from its current distribution (seeded, reproducible). pi becomes the point mass δσ (red) and the change δσ − pi is passed through the learned LSM links to every item whose model uses i, updating their distributions once. The next question is asked in this updated Ψ.

How not to read it

  • Links are learned statistical dependencies between survey responses, not causal effects.
  • One question = one update of Ψ (the native hard observation). No further relaxation is run.
  • All mathematics runs in the native PsiSim runtime; the page only draws its snapshots.
