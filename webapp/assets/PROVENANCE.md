# Provenance: `catalog.json` and `metadata/`

Generated by `webapp/build_catalog.py` from a DTAG checkout; the webapp does
not need DTAG at runtime. Models themselves are not stored here: they are
downloaded on demand from the public DTAG model release (GCS) and
SHA256-verified by `applications/psisimulation/fetch_model.py`.

## `catalog.json`

One entry per model of the public release manifest, with:

| field | source |
| --- | --- |
| `family`, `archive_bytes` | release manifest |
| `period` | GSS: survey year · Afrobarometer: round fieldwork years (`dtag_recommend.AFRO_ROUND_YEARS`) · Eurobarometer: fieldwork dates (`configs/eurodates.csv`) · WVS7: `A_YEAR` support |
| `countries` | GSS: United States · Afrobarometer / Eurobarometer: the model's own country variable (`configs/model_coverage.json`), normalised with DTAG's country matcher · WVS7: countries whose centroid snaps within 2° of the model's coordinate support (DTAG's rule) |
| `auto_select` | Eurobarometer only: false for cumulative/trend files, which are offered last |

A small curated table in `build_catalog.py` merges survey labels that name the
same country (e.g. "Germany Total" → Germany) and drops non-country labels
("Other", "Not Germany", bare codes).

## `metadata/<family>/<name>.json.gz`

`{variable: [short label, question text]}` for each model, from DTAG's
semantic maps (`maps/`), resolved per model as in
`dtag_engine.canonical_map_key`:

- GSS: codebook labels; a year whose map has no text borrows the label of the
  same variable from the nearest year (year-specific rows preferred).
- Afrobarometer: `question_text` split at " | " into label and question.
- WVS7: `pdf_short_label` and `question_text_filled`.
- Eurobarometer: `variable_label` and `question_text_filled`; scraped table
  headers and study titles are discarded.

Answer categories are not stored here: they come from each model's native
source maps at load time.

Regenerate:

```bash
python3 webapp/build_catalog.py --dtag /path/to/DTAG
```
